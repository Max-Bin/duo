# Duo v1.0.0 Release Notes

**Release date:** 2026-04-09

Duo reaches its first stable release. This version represents a complete, tested,
and documented AI agent orchestration runtime ready for production use.

## Highlights

### Commander / Executor Architecture
Duo splits AI agent work into a **Commander** (Python CLI that makes decisions)
and an **Executor** (Copilot CLI that writes code), connected via a file-based
protocol over tmux. Each task gets an isolated git worktree, enabling true
parallel agent execution without merge conflicts.

### CEO Command Family
A suite of 4 commands (`ceo-wait`, `ceo-select`, `ceo-approve`, `ceo-status`)
for automated dialog handling. Wait for dialogs, select options, and approve
permissions — all with PR budget safety guards.

### `duo think` — Plan Before You Spend
Brainstorm with Claude Code in a tmux pane without consuming Premium Requests.
Use `--ask` to pose questions, `--finalize` to generate a plan, and
`--from-thinking` to carry that context into a task.

### Pure Dialog Detection
ANSI-stripped pane reading with regex-based dialog classification. Detects
permission dialogs, option dialogs, and text input dialogs reliably across
terminal color themes. No false positives from scrollback content.

### Premium Request Budget Protection
Every PR consumption is journal-logged. `duo cost` reports usage per task.
`--budget N` enforces limits with non-zero exit codes. The commander checks
budgets before sending prompts, preventing runaway spending.

## Upgrade Path

This is the first stable release. There are no breaking changes from
v0.x development versions — the file protocol, CLI interface, and
configuration format are all forward-compatible.

If upgrading from v0.6.x or v0.7.x:

```bash
cd duo && git pull && uv sync && uv pip install -e .
```

No configuration migration is needed.
