# Performance Baseline

> Generated by `duo bench all` — reference point for regression detection.

## Environment

- **Architecture:** arm64 (Apple Silicon)
- **Python:** 3.12.12
- **Iterations:** 1000 per benchmark

## Baseline Results

### Dialog Detection

| Benchmark | ops/sec | avg (µs) | p99 (µs) |
|-----------|---------|----------|----------|
| Option dialog detect | ~153K | 6.5 | 9.3 |
| Text dialog detect | ~133K | 7.5 | 10.4 |
| Main prompt detect | ~959K | 1.0 | 1.5 |
| Spinner detect | ~2.5M | 0.4 | 0.6 |

**Summary:** All dialog detection routines run sub-10µs.
Spinner and prompt detection are CPU-cache-hot regex matches.

### File Protocol

| Benchmark | ops/sec | avg (µs) | p99 (µs) | throughput |
|-----------|---------|----------|----------|------------|
| Write JSON | ~2.2K | 465 | 670 | ~560 KB/s |
| Read JSON | ~71K | 14 | 18 | ~18 MB/s |

**Summary:** Writes are bounded by `fsync()` (intentional for crash
safety). Reads are memory-mapped and fast.

### Journal Append

| Benchmark | ops/sec | avg (µs) | p99 (µs) | notes |
|-----------|---------|----------|----------|-------|
| Append event | ~17K | 59 | 74 | Single JSONL line + fsync |
| Read JSONL | ~1.1K | 906 | 2158 | ~1.1M events/sec replay |

**Summary:** Append is fast enough for interactive use (~60µs).
Replay throughput is dominated by file I/O and JSON parsing.

## Regression Thresholds

Each benchmark has a maximum allowed degradation percentage.
Exceeding these thresholds indicates a performance regression.

| Category | Threshold | Rationale |
|----------|-----------|-----------|
| Dialog detection | 25% | Regex-based, should be stable |
| File protocol write | 30% | fsync-bounded, OS-dependent |
| File protocol read | 20% | Memory-bound, stable |
| Journal append | 25% | fsync-bounded |
| Journal read | 30% | I/O-bound, more variable |

## Running Regression Checks

```bash
# Quick check against saved baseline
make bench-check

# Manual check
scripts/bench-regression-check.sh

# Save new baseline after intentional changes
duo bench all --json-output --save
```

## Notes

- Write benchmarks vary ±50% due to OS filesystem caching and fsync timing
- Run benchmarks on a quiet system (no heavy I/O) for consistent results
- The `--save` flag stores results in `~/.duo/bench-results/` with timestamps
